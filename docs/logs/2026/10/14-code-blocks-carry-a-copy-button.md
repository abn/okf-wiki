Code and text blocks carry a copy button in their top-right corner, added client-side and a11y-compliant (a real button with an accessible name and focus ring). It uses the same copy glyph as the diagram toolbar and is hidden when printing. `design/rendering.md` and `reference/themes.md` say so.
