`usage/cli.md`, `reference/configuration.md`, `design/rendering.md` and `reference/themes.md` document `--multi-site` (or `OKF_WIKI_MULTI_SITE`), which reads the content directory as a tree: each directory with an `index.md` is a wiki rendered at its own path, and every other directory is a group given a generated index of its children.
