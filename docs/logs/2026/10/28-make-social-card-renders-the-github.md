`make social-card` renders the GitHub social preview card in a light and a dark palette at 1280x640 from `scripts/social-card/card.html`, which imports the theme's tokens and fonts and shows the committed brand mark. The cards live under `.github/assets/social/`, and the contribution guide and README record the target and its Chrome requirement.
