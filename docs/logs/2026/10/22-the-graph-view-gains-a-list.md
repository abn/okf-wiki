The graph view gains a list beside the drawing, with the visible nodes and edges, connection counts, link text and edge anchors. Selecting a list node opens the same details and focus as the drawing, and the list follows Filter, Show, Tags, focus and the URL state. Node rows use one roving tab stop, and a large catalogue caps its first page with Show all buttons. At narrow widths the list stacks below the drawing. `usage/graph.md`, `reference/graph.md`, `design/rendering.md`, `reference/themes.md`, `usage/offline.md` and `design/graph-evolution.md` say so.
