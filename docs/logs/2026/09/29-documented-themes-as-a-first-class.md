Documented themes as a first-class concept. A theme is a directory layered over an embedded default at run time, so re-skinning a deployment is a read-only mount and an environment variable rather than a new image. `reference/themes.md` documents the manifest, the resolution order, the DOM contract and the asset contract; `design/branding.md` covers what a theme owns.
